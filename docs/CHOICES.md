# Technical Choices

## YOLOv8

Selected because it provides fast and accurate person detection with minimal setup and strong real-time performance.

## ByteTrack

Chosen for stable multi-object tracking and visitor ID persistence across frames.

## FastAPI

Used to expose analytics through REST APIs with high performance and automatic documentation.

## Streamlit

Selected for rapid dashboard development and interactive business intelligence visualizations.

## Pandas

Used for transaction processing, KPI calculation, and revenue analysis.

## Docker

Used to package the application into a reproducible deployment environment.

## Trade-offs

A lightweight architecture was preferred over a distributed microservice design due to project scope and submission timeline.

Future versions can incorporate real-time streaming, heatmaps, queue detection, and inventory intelligence.
